

CI Final Assignment: Data Analysis & Machine Learning
Welcome to the repository for my GCI final assignment. This project involves processing company data, applying machine learning models, and extracting actionable business insights.

Repository Contents
Here is a breakdown of the files included in this project and their purposes:

README.docx (1).pdf: The official problem statement outlining the core objectives and requirements of this assignment.

notebook (2).ipynb: The primary Jupyter/Colab notebook containing all the Python code for data preprocessing, exploratory data analysis (EDA), and machine learning model implementation.

Record.zip , Client.zip: The raw dataset used to train and evaluate the models. (Note: This must be unzipped prior to running the notebook).

ENG_Company _A_ Dataset Overview.docx: The data dictionary. It contains the full forms and detailed explanations of all the initials and abbreviations used within the dataset.

report (2).pdf: The final presentation summarizing the project's methodology, key analytical findings, and conclusions.

How to Navigate This Project
Understand the Goal: Start by reading the README.docx (1).pdf to understand the problem I am solving.

Review the Data Terms: Keep ENG_Company _A_ Dataset Overview.docx handy to understand the specific variables used in the dataset.

Explore the Code: Extract Record.zip and open notebook (2).ipynb (via Google Colab or Jupyter) to see the step-by-step data pipeline and machine learning implementation.

View the Results: Open report (2).pdf for a high-level, visual summary of the final outcomes.
